# 고령 유동인구를 고려한 금천구 무더위쉼터 최적 입지 분석

## 데이터 출처 목록

2026년 9월 18일 작성

확보 상태는 미착수, 신청중, 확보, 불가 중 하나로 기록하며 W1 종료 시점에 갱신한다.

---

## 1. 주 사용 데이터

분석의 골격을 구성하는 6종이다.

| 데이터명 | 원천 | 용도 | 상태 |
|---|---|---|---|
| 50m 격자 성ㆍ연령별 유동인구 | 한국데이터산업진흥원 | 60대 이상 유동인구 기반 수요 가중치 | 미착수 |
| 50m 격자 시간대별 유동인구 | 한국데이터산업진흥원 | 폭염 시간대 분포, 야간 보조 분석 | 미착수 |
| 서울시 무더위쉼터 현황 | 서울 데이터허브 | 기존 시설 위치 및 운영 정보 | 미착수 |
| 서울시 공공시설 위치정보 | 서울 데이터허브 | 신규 후보지 구축 | 미착수 |
| 서울시 보행 네트워크 | 서울 데이터허브 | 최단 보행거리 산출 | 미착수 |
| 서울시 행정구역 경계 | 서울 데이터허브 | 분석 범위 설정, 공간 필터링 | 미착수 |

유동인구 2종이 분석의 핵심 입력이다. 이 자료를 확보하지 못하면 주민등록인구로 대체해야 하며, 그 경우 거주 인구와 활동 인구의 차이를 다루는 분석의 전제가 성립하지 않는다.

## 3. 검증용 데이터

| 데이터명 | 원천 | 접근 경로 | 용도 |
|---|---|---|---|
| 금천구 2025년 추가 지정 14개소 목록 | 금천구청 | 정보공개청구 또는 부서 문의 | 선정 결과와 실제 정책 결정의 대조 |
| 전국무더위쉼터표준데이터 | 행정안전부 | data.go.kr/data/15013199 | 시설구분, 면적, 이용가능인원, 냉방기 보유 |
| 온열질환 응급실감시체계 | 질병관리청 | kdca.go.kr | 사각지대와 피해 분포 대조 |
| 119 구급 이송 기록 | 서울소방재난본부 | 정보공개청구 | 지점 단위 확보 시 검증력 향상 |

2025년 추가 지정 14개소의 목록 확보가 검증의 핵심이다. 본 분석이 선정한 입지와 실제 행정이 선정한 입지를 대조하면, 일치 여부와 무관하게 결과를 해석할 수 있다. 일치하면 방법론이 실제 정책 판단과 부합한다는 근거가 되고, 불일치하면 행정적 배분과 수요 기반 배분의 차이를 제시하는 근거가 된다.

온열질환 자료는 공개 통계의 공간 단위가 시군구로 제한되어 금천구 내부를 구분하지 못한다. 정보공개청구로 행정동 또는 지점 단위 확보를 시도하되, 실패 시 서울시 25개 자치구 단위 분석으로 대체한다.

## 6. 확보 우선순위

리드타임이 긴 순서로 처리한다.

1. 안심구역 유동인구 자료 이용 신청. 승인 대기 발생
2. 금천구청 2025년 추가 지정 목록 문의. 정보공개청구 시 처리기간 10일 이상
3. 119 구급 이송 기록 정보공개청구. 처리기간 10일 이상
4. 도로명주소 전자지도 신청. 승인 1시간 내외
5. 나머지 공개 자료. 즉시 내려받기

1번과 2번이 지연되면 대체 경로로 전환한다. 유동인구 자료의 승인 전에는 공개 자료만으로 분석 절차를 완성해 두고, 승인 후 입력 자료만 교체하는 구조로 코드를 작성한다.
