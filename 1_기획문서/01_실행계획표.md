## 3. 주차별 계획

### W1 (9.18 ~ 9.24) 착수 및 데이터 신청

유동인구 자료의 이용 신청은 승인까지 대기가 발생하므로 다른 작업에 우선하여 처리한다.

| 작업 | 담당 | 산출물 |
|---|---|---|
| 참가 신청 및 팀 등록 | PM | 접수 확인 |
| 데이터안심구역 이용 신청, 방문 일정 예약 | PM | 방문 승인 |
| 50m 격자 유동인구 자료 이용 신청 | 데이터 | 신청 접수증 |
| 운영사무국 문의: 방문일수 산정 기준, 반출 규정 | PM | 문의 회신 |
| 선행 연구 검토: MCLP, p-median, 폭염 취약성 | 분석 | 검토 노트 |
| 공간자료 수집: 무더위쉼터, 공공시설, 보행 네트워크, 경계 | 데이터 | 원자료 |
| 분석 환경 구축 | 개발 | 저장소 초기화 |

W1 종료 시점에 유동인구 자료 신청이 접수되지 않은 경우 즉시 대응한다.

### W2 (9.25 ~ 10.01) 안심구역 1차 방문 및 수요지 구축

| 작업 | 담당 | 산출물 |
|---|---|---|
| 안심구역 1차 방문, 연속 3일 체류 | 전원 | 방문일수 3일 |
| 유동인구 자료 구조 파악, 데이터정의서 검토 | 데이터 | 변수 사전 |
| 50m 격자 수요지 생성 | 분석 | 수요지 자료 |
| 60대 이상 여름철 주간 유동인구 추출 및 가중치 산출 | 분석 | 가중치 자료 |
| 기존 무더위쉼터 93개소 정제 및 좌표 확인 | 데이터 | 기존 시설 자료 |
| 2025년 추가 지정 14개소 목록 확보 | 데이터 | 검증용 자료 |

2025년에 실제로 추가 지정된 14개소의 목록은 결과 검증에 사용하므로 확보 여부를 W2 내에 확정한다. 금천구청 정보공개청구 또는 담당 부서 문의로 확보한다.

### 예선 이후 (10.23 ~ 11.19)

예선 결과 발표까지 약 3주의 여유가 있다. 이 기간에 본선 발표자료를 준비한다. 금천구청 담당 부서 면담, 선정 시설의 현장 확인과 온습도 실측, 웹 지도 제작, 예상 질의에 대한 답변 정리를 포함한다. 예선 통과 통보 이후에 착수하면 준비 기간이 부족하다.

## 4. 역할 분담

5인 기준이며 인원이 다를 경우 역할을 병합한다.

| 역할 | 책임 범위 |
|---|---|
| PM | 일정 관리, 대외 문의, 문서 총괄, 제출 |
| 데이터 | 수집, 정제, 좌표 확인, 자료 관리 |
| 분석 | 가중치 산출, 최적화 모형, 민감도, 검증 |
| 개발 | 네트워크 구축, 거리 행렬, 파이프라인 |
| 시각화 | 지도, 도표, 발표자료 |

전원이 안심구역 방문에 최소 1회 참여한다. 방문은 팀 단위로 점수가 산정되나 자료 구조에 대한 이해도가 분석 품질에 영향을 준다.

## 7. 사전 확인 사항

데이터안심구역 방문일수의 산정 기준을 확인한다. 연속 체류 3일이 3회로 인정되는지 또는 방문 회차로 산정되는지에 따라 방문 계획이 달라진다.

분석 결과의 반출 범위를 확인한다. 안심구역 내부에서 산출한 결과를 기획서에 어느 수준까지 수록할 수 있는지에 따라 산출물의 집계 수준을 조정한다.

기존 무더위쉼터 93개소와 2025년 추가 지정 14개소의 정확한 목록을 확정한다. 언론 보도에는 총 94개소로 언급된 사례가 있으므로, 금천구청 자료로 기준 시점과 개소 수를 확인한다.
